# 品牌界面与协议边界

console → 品牌二级界面 → mosila 或魔灯客。mosila保留原有四页、EEA0/EE01、213种灯效与现有存储。魔灯客只适配九号N/F/M大灯3.0（ID58），使用FFF0/FFF2/FFF1、独立三路页面、MdkProtocol/MdkState/MdkProfiles，详见 MODENGKE_NFM30.md。

换品牌断开GATT、停止扫描并取消队列；相同品牌返回保留会话。设备记录、连接记忆和最后查看设备按品牌/型号分开；名称缓存也按品牌独立保存，不用型号名称冒充广播名。魔灯客必须得到有效型号回复才能发送灯光设置。

原light偏好仅供mosila，console偏好保存当前品牌及各品牌页签。离线草稿必须先确认或取消再换品牌。打开品牌选择页不主动断开当前连接；延迟到达的连接事件不会关闭品牌选择页。


0.3.1：扫描会话绑定品牌与递增代次。每次停止或切换使旧回调失效（包含已投递到主线程的任务、批量结果和失败回调）。扫描列表根据另一个品牌的已保存设备/连接记忆，以及明确的广播名称/服务过滤；没有品牌信息的新设备仍可扫描，但不会被自动归类为已保存大灯。旧设备对象需仍属于当前列表才能连接。

名称缓存为bluetooth_names_mosila_v2和bluetooth_names_modengke_p58_v2，不导入旧共享bluetooth_names。参数和连接记忆保留原路径，已保存名称仍有各自的回退来源。会话日志用EnumMap按品牌保留，切换仅展示当前品牌的日志。待处理权限/蓝牙启用请求也绑定发起品牌。
