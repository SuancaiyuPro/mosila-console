# 每设备参数与恢复

存储：应用私有 SharedPreferences `device_profiles`，键为完整蓝牙地址。schema=1，包含 packets、最后输出类型 active、更新时间。数据表示用户请求的配置，不是设备状态回读或固件 ACK。恢复时不重新保存快照，避免把旧值盖过期间的新操作。

| 项目 | 保存内容 | 恢复 |
| --- | --- | --- |
| 灯光开关 | CMD1 开关、RGB、强度 | 开启在输出前，关闭在最后 |
| 纯色 | CMD2 RGB、强度 | 最后使用纯色时恢复 |
| 灯效 | CMD3 编号、速度、灯效 A/B | 最后使用灯效时恢复 |
| 开机效果 | CMD4 模式、点数、独立 RGB、原固定参数 | 恢复 |
| 刹车 | CMD5 两个效果参数 | 恢复 |
| 转向 | CMD6 两个效果参数 | 恢复 |
| 长按光高 | CMD7 最后操作方向 | 仅记录，不自动重放 |
| 自检 | CMD8 启用值 | 恢复 |
| 总 A 路 | CMD9 路0开关 | 独立恢复 |
| 总 B 路 | CMD9 路1开关 | 独立恢复 |
| 光高数值 | CMD10 档位0–18 | 恢复 |
| RGB 线序 | 原始91包，值1–6 | 最先恢复 |

未设置过的项不构造默认包。全部项目均设置过时会保存12项（含即时动作记录和非当前输出缓存），一次恢复最多10个包。颜色与灯效同时保留，恢复时只发送最后使用的一组，避免互相覆盖；显式关灯最后发送，保证最终请求为关闭。中间配置是否引发实物短暂变化仍取决于固件。

写入调度：服务就绪后等700ms；恢复包必须收到上一包的 Android 写入回调，再等400ms；普通控制回调后等150ms。不同设备各自串行，记录不跨地址复制。无响应写入没有大灯执行回报，节流降低连发压力但不保证无线传输永不丢失。

写入拒绝/错误会清空本次待发队列，记录仍保留；2.5秒无写回调则断开，避免旧回调与下一条混淆。断开取消旧队列和定时器。高频待发控制仅合并同命令，CMD9须同时匹配A/B路，恢复快照不被合并。

连接记忆继续只记录最近成功验证的大灯。设备参数与连接记忆分开存放，不把0.1.6之前的全局缓存猜测分配到某一台。当前实现没有固件状态回读解析。用户提供的现场日志显示EE02订阅成功，但读取为空、切换灯效和颜色后没有通知；这也是采用本地配置恢复而非声称状态同步的原因。


## 0.1.8 跟进

档案增加name元数据，schema仍为1，旧记录正常加载；仅记录名称没有设置时不构造任何灯光指令。设备页可离线编辑已知地址，切换离线档案会清除其他设备的控制选择。离线数据直接记入该地址档案，发送反馈明确区分保存与入队。通用预览不分配给陌生地址；即时移动动作不进行离线排队。

所有持久参数的待发队列按字段合并，A/B路使用独立键、线序也可合并；正在写入的包和恢复快照不更改。按字段合并将连续开关等操作收敛到最后一次请求，减少队列积压。单个JSON参数字段解析失败不再中断兄弟字段恢复。


## 0.1.9 离线草稿

用户在离线会话内修改的持久参数按字段暂存在内存列表，重复同字段只保留最后值及操作次序。确认时重新加载该地址最新档案，按操作次序应用本次修改，再通过一次SharedPreferences写入保存，保留其他已确认字段及名称。取消不执行档案写入，返回键同取消。

顶部“编辑中”及确认 / 取消跨调色、灯效、设置页存在。草稿会话暂停目标切换，自动重连的设备取消控制选择，发送入口优先处理草稿，因此不会把未确认参数下发给刚重连的大灯。连接仍可按既有功能恢复上次已确认配置。后台不提交，进程重建回到已确认档案。普通在线操作维持自动保存。


## 0.1.10 入口修正

离线编辑仅由设备页按钮启动。发送入口不再因“没有选中已连接设备且存在档案”自行创建草稿；普通离线预览不会写设备档案。扫描名称缓存独立存放于bluetooth_names，最多256项，不改变设备参数身份、恢复地址匹配或草稿规则。


## 0.3.2 手动删除

DeviceProfiles.delete按地址移除MOSILA记录；MdkProfiles.delete删除state及updatedAt，但保留不含参数的设备名称/品牌归属元数据。连接记忆与广播名缓存不删除。UI的设备列表和离线已保存列表都有确认删除入口，弹窗捕获品牌并在确认时复核当前品牌和草稿状态。

BleController.deleteSavedParameters先停止目标设备待发队列；若有正在执行/待执行的恢复或手动写入，关闭此设备GATT，使后续迟到回调失效，再删除对应品牌的存储。没有待写内容时维持连接。没有向灯具发重置指令，也不能撤销已经交给蓝牙的单帧。UI同步清除目标设备的预览缓存/最后展示地址，避免旧字段残留；连接后新的操作仍按原逻辑自动保存。
