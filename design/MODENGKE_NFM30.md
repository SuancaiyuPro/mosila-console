# 魔灯客 / 摩灯客：九号 N/F/M 大灯 3.0

## 适配边界

入口保留用户要求的“魔灯客”名称；所提供原版 APK 的文件名及品牌写作“摩灯客”。本版仅接入大灯产品中的产品 ID **58**，p_key **JHDD30**。不接入其他子品牌、2.5 版、普通版、尾灯或转向灯。

确认来源：用户提供的摩灯客 2.2.0 APK 内 `assets/apps/__UNI__C7FA623/www/app-service.js`；webpack 模块 `daf8`（ble/protocol.js）、`3900`（CRC）、`9bbe`（字节工具）、`ba11`（BLE）、`91ca`（默认数据）、`8565`（控制页）、`9a4c/dd7e`（通道）、`483b/a3a8`（电调）。APK SHA-256 见 modengke-evidence。

产品和固件参数并非静态打包在 APK，原版从自己的公开接口读取。此次通过原版调用方式只读获取：

- `https://api.wlgk.xyz/api/product/list?typeId=7`，筛选 ID58。
- `https://api.wlgk.xyz/api/firmware/config?pId=58&version=1.0.0&type=1`。
- `https://api.wlgk.xyz/api/effect/list?type=3`。

所用配置已固化于 modengke-evidence，测试版不依赖这些服务器，也没有 INTERNET 权限。未来固件可能增加功能，本版仅提供已核对的这组功能；没有进行 OTA 升级、账号激活或设备信息上报。

## BLE 与握手

- Service FFF0，写 FFF2，通知 FFF1（均为标准 Bluetooth base UUID）。
- GATT 服务发现 → MTU请求256（实际必须≥51）→ FFF1标准CCCD订阅并等待回调 → 原版 A9 查询 → 等待有效 CRC 的 B9 产品回复及查询写回调。
- B9 产品 ID 必须为58；错误型号、通知失败、MTU不足或无回复均不进入ready、不记为成功连接、不恢复参数。
- 成功后记忆地址和名称。首次未保存参数时不下发默认灯光设置。返回的固件版本只作型号/版本展示，不能推断当前灯效。
- 每台设备独立帧重组器支持分片、连帧、噪声和CRC错误后重新同步；不将未经验证的通知覆盖UI。
- 优先 WRITE（有应答）；仅设备仅支持 WRITE_NO_RESPONSE 时回退。每次写等待Android回调，然后至少500ms再写下一条，恢复开始前等待700ms。写回调不是灯具执行成功确认。缺失回调2.5秒断开，不盲目重发。

## 报文

`AA 55 | ASCII 0001 | TYPE | DATA | CRC_LO CRC_HI | 0D 0A`

CRC16/Modbus，初值FFFF，多项式A001，计算范围含包头至DATA。6位ASCII蓝牙密码默认123456，与原版一致，不是卡密。

| TYPE | DATA（密码之后的字段） | 是否保存/恢复 |
|---|---|---|
| A1 | 线路、灯效、档位、闪烁、颜色数、开关、方向、颜色宽度、灯珠数、亮度、RGB序列 | 按线路分别保存 |
| A0 | 开机效果2/3/4 | 是 |
| A5 | 开机R/G/B | 是 |
| A8 | 颜色自检0/1 | 是 |
| A6 | 高低自检、效果、内部模式、内部速度 | 是 |
| A3 | 3、绝对位置0–100 | 是 |
| A9 | 无密码，无参数 | 型号查询，不保存 |
| B9 | 版本3字节、分区、产品ID大端2字节、可选设备标识12字节 | 仅核对型号 |
| EE | 请求TYPE、结果码1=成功 | 仅记录，不猜测当前状态 |

没有开放A4线序调试、A7连续移动、AA转向开关、AB验车、AC其他产品特效、DB调试、CC固件写入。

## 保存与离线编辑

命名空间 `modengke_p58_profiles` 与 `connection_memory_modengke_p58`。保留 MOSILA 原来的 `device_profiles` / `connection_memory`，名称缓存自0.3.1起也完全分开。换品牌断开旧会话并清空队列，重新按对应UUID发现和核对。

参数按MAC隔离，保存每路开关、颜色、非活动颜色缓存、多色序列、灯效、档位、闪烁、方向、宽度、亮度，以及开机、自检、电调、绝对位置、同步偏好。只恢复曾明确配置的指令，避免给新设备发送臆造的默认配置。先恢复开机/自检/电调，然后三路灯光各一帧；不先发单色再发灯效相互覆盖。未发送的同项改动合并，三路分别合并。

没有连接时调整只预览，不自动进入编辑，也不修改已有设备记录。必须在设备页明确点击离线编辑；固定顶部显示编辑中、确认和取消。确认一次保存整份草稿；取消/返回丢弃。草稿期间禁止换品牌；自动连接只恢复已提交记录，不发送草稿。
